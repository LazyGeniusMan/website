At [PT Navcore Nextology](/experience/navcore-2023), alongside BPMN and DMN models and ERP integrations, I automated repetitive tasks using Python scripts. No platform purchase, no committee. Just the boring work disappearing.

## Find the repetition first

Automation starts by watching the work: the same spreadsheet reshaped every Monday, the same status copied between systems, the same report assembled by hand. If a task happens the same way twice, it is a candidate.

## Script the task, keep the process

The scripts never replaced the process model; they executed the steps the model already described. Low-code tools combined BPMN, DMN, and REST API for the heavy flows, while Python handled the gaps between systems that no integration covered yet.

## Boring is the point

Good automation is invisible: the task simply stops taking afternoons. That experience, detailed functional requirements then small reliable tooling, now shapes how I approach business process automation and improvement engagements.

Automate the repetition you can see this week. The platform conversation can wait until the scripts tell you what it must do.
