## Problem

An enterprise resource planning build that starts from undocumented habits encodes each department's informal workarounds into the system. Without gathered requirements and agreed specifications, development and verification have nothing to anchor to.

## Approach

Project at PT GITS Indonesia. Involved as Implementation Team intern. Conducted interviews and analyzed documents to gather user requirements for an ERP system, documented processes with flowchart diagrams, modeled the relational database with entity-relationship diagrams alongside back-end developers, coordinated wireframes with front-end developers, co-authored the Software Requirement Specification, prepared the Standard Operating Procedure and the Functional Specifications Document, then verified the built system with users.

## Result

The ERP build proceeded from specified requirements and procedures that users had verified, rather than from assumed processes.

Project at PT GITS Indonesia, 2021. Internal deliverable, no public listing.
