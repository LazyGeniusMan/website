## Problem

An inventory system built without written functional specifications encodes guesses about stock movements, reservations, and adjustments. Every warehouse edge case then surfaces as a production incident instead of a reviewed requirement.

## Approach

Project at Makers Institute. Involved as Business Process Designer. Prepared functional specification documents and designed wireframes for an Inventory Management System, so the build follows reviewed requirements rather than assumed flows.

## Result

The inventory build proceeds from specified functions and wireframes that reviewers and developers share.
