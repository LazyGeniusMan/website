## Problem

Users of Microsoft Office often switch between apps when working on their taks to research, validate, ask AI assistant, etc. Repetitive tasks also must done manually by the users.

## Approach

As Backend Engineer, I designed, implemented, deployed and maintained supporting backend services in VPS such as REST API services, LLM Gateway and MCP servers using doco.cd for kinaia so that it can embed chat interface directly in Microsoft Office Suite as Add-ins.

## Result

Users of Microsoft Office can do all of their tasks seamlessly in Microsoft Office without switch between apps. Repetitive tasks also can be automated using Natural Languange using AI agents.
